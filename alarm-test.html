Before you start (once)
  1. Open Shortcuts, tap +, name it exactly Rotapp test.
  2. Add the action Show Result, and set what it shows to Shortcut Input.

Tests

Each one sends a fake 3-month alarm schedule (dates and times only) to the "Rotapp test" shortcut, which should show it. Then come back here and the page notes how you got back and how long it took.

1 = how B (button) feels. 2 = how A (automatic) feels when Rotapp starts it without a direct tap. 3 = asks Shortcuts to bring you back automatically; see whether it returns to this home-screen app or to Safari.
